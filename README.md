# ❤️ Heart Disease Prediction Using Machine Learning

## 📌 Project Overview
This project is about predicting the likelihood of heart disease. This project implements a Logistic Regression algorithm using a heart disease dataset that predicts the possibility of heart disease in the 
future created with streamlit that takes the relevant information from the user and makes the prediction.
## 🎯 Objective

- Develop a Machine Learning model that can predict the possibility of heart disease
- Apply necessary imputation techniques and feature scaling to make accurate predictions
- Construct a web application prototype with the help of streamlit
- Display the outcome of the prediction to the user.

## 🛠️ Techonologies Used
- Pandas
- Numpy
- Scikit-learn
- Joblib
- Streamlit
- Google Colab, VS Code
- GitHub

## ✨ Features
- Web application with interactive interface

- Predicts possibility of heart disease using Machine Learning
- Preprocess the data using imputer and scaler
- Display the prediction results in the web application
## 📂 Project Files
- app.py — Streamlit application and prediction logic.
- heart_disease_model.pkl — Saved trained model and preprocessing objects.
- requirements.txt — Required Python libraries and dependencies.
- heart_disease_prediction.ipynb — Jupyter Notebook containing the model training code.

## 🧠 ML Model
The ML model used for this project is `Logistic Regression`. This algorithm helps to predict a binary class like `Yes` or `No`. In this project, it predicts whether a person has a high risk for heart disease and the result will be `1` if the model predicts a heart disease and `0` if it does not predict a heart disease.
## ⚠️ Disclaimer
This project is a prototype for educational purposes and the result from this model must not be used for any medical purposes. Please consult a doctor or a specialist for medical advice.
